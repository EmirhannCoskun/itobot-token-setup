# İTOBOT Grant Tracker

İTOBOT Grant Tracker, Telegram bot tokenının güvenli şekilde yapılandırılmasını, doğrulanmasını ve local olarak saklanmasını sağlayan Flask tabanlı bir kurulum uygulamasıdır.

## ✨ Özellikler

- Telegram Bot Token kurulumu
- Telegram Bot API üzerinden gerçek token doğrulaması
- Telegram Bot Token format kontrolü
- Token'ın local olarak saklanması
- Atomik config dosyası yazımı
- Token değiştirme
- Token silme
- Token göster / gizle
- CSRF koruması
- Rate limiting
- Content Security Policy (CSP)
- Güvenlik HTTP header'ları
- Maksimum request boyutu sınırı
- Başarılı kurulum ekranı
- Kapsamlı pytest testleri

## 🛠️ Kullanılan Teknolojiler

- Python
- Flask
- Requests
- HTML5
- CSS3
- JavaScript
- Pytest

## 📋 Gereksinimler

- Python 3.10 veya üzeri
- pip
